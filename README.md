# Kurs "Virtuelle Trainingswelten" @ TUM

**MVP of a Virtual SpielStopp Store for More Effective Onboarding of New Employees**  
**Grade: 1.0 (Excellent)**

---

## Overview

This project is a **Minimum Viable Product (MVP)** developed as part of the course **"Virtuelle Trainingswelten"** at **Technical University of Munich (TUM)**. The application simulates a SpielStopp store environment to provide an interactive and engaging training experience for new employees, improving their onboarding efficiency and familiarity with store operations.

---

## Key Features

- **Realistic Virtual Store Environment**: Simulates the layout and workflow of a typical SpielStopp branch.
- **Interactive Training Modules**: Guides users through various tasks commonly performed by employees.
- **Immersive Learning**: Enhances the learning process with engaging, scenario-based training activities.
